---
name: Telegram subtitle bot
description: User-stated product requirements for video transcription and subtitle output.
---

The user wants a Telegram bot that can receive videos up to 27 minutes, transcribe speech in the language spoken in the video, and return a subtitle file with timecodes. They want the service to be free.

**Why:** These are explicit requirements the user gave for this project.

**How to apply:** Keep transcription free of paid per-minute APIs, preserve the source language rather than translating, and retain the 27-minute duration cap unless the user changes these requirements. Be clear about any Telegram file-size or hosting limits that prevent a requirement from being met.
